# P5S Android

Projeto experimental de diagnóstico e pesquisa para Android, voltado a avaliar a viabilidade técnica de um port nativo de Persona 5 Strikers.

## Estado atual

Este repositório está iniciando com documentação. O primeiro marco será um aplicativo Android de diagnóstico para verificar a disponibilidade de Vulkan no dispositivo. **Isto ainda não é um port jogável.**

## Limites

- O projeto não inclui assets, executáveis, músicas ou código proprietário do jogo.
- Um teste de Vulkan não comprova que o jogo possa ser portado ou executado no aparelho.
- A implementação deve usar somente arquivos e recursos obtidos legalmente.

## Próximos passos

1. Criar a estrutura Android/Gradle.
2. Implementar uma tela de diagnóstico Vulkan.
3. Configurar GitHub Actions para compilar um APK de depuração.
4. Testar o APK no dispositivo-alvo e avaliar a viabilidade técnica.
